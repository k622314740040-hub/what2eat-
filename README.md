## 📚 TÀI LIỆU DỰ ÁN (PROJECT SPECIFICATIONS)

Repository này chứa toàn bộ 4 bộ tài liệu thiết kế và quy hoạch sản phẩm cho dự án **WHAT2EAT**:

1. **[BUSINESS PLAN](./BUSINESS%20PLAN.pdf)**: Phân tích thị trường, mô hình kinh doanh B2C/B2B, kế hoạch tiếp thị và phân bổ vốn.
2. **[PRODUCT REQUIREMENT DOCUMENT (PRD)](./PRODUCT%20REQUIREMENT%20DOCUMENT.pdf)**: Định vị vấn đề, giá trị cốt lõi, luồng sử dụng và phạm vi tính năng MVP.
3. **[TECHNICAL PLAN](./TECHNICAL%20PLAN.pdf)**: Cấu trúc Tech Stack (React 19, TypeScript, Tailwind v4), Database Schema và 29 REST API Endpoints.
4. **[UI/UX & USER STORIES](./UI_UX%20%26%20USER%20STORY.pdf)**: Tổng hợp 13+ User Stories, Acceptance Criteria và UI Mapping cho 6 màn hình chính.

---

## 🛠️ TECH STACK

- **Frontend**: React 19, TypeScript, Vite 7, Tailwind CSS 4, Radix UI / shadcn/ui.
- **State & Routing**: Zustand, TanStack Router.
- **Backend (Proposed)**: Node.js, Express, Prisma ORM, PostgreSQL.
